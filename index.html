How to add this to Outlook
  1. Fill in the fields above — the preview updates live.
  2. Click Copy Signature.
  3. In Outlook, go to File → Options → Mail → Signatures (desktop) or Settings → Mail → Compose and reply (web).
  4. Create/select a signature, click inside the edit box, and paste (Ctrl+V).
  5. Save.
